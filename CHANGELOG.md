# История изменений — Podlets TG Proxy

Все значимые изменения в проекте **Podlets TG Proxy** документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
и проект придерживается [Семантического версионирования](https://semver.org/lang/ru/).

---

## [1.0.1] - 2026-11-08

### Исправлено
* **Проверка собственных прокси**:
  * Скрыта лишняя плашка рейтинга («★ 0») у карточек прокси при ручной проверке пользовательского списка, а также у публичных серверов без реакций.
  * Скрыта панель сортировки («По пингу / По рейтингу») при проверке своих прокси — пользовательский список теперь автоматически ранжируется по минимальному пингу без лишних элементов интерфейса.
* **Интерфейс поиска прокси**:
  * Удалена дублирующая кнопка «Свои прокси» из центра приветственного экрана при пустом списке (кнопка осталась в шапке в верхнем левом углу).
* **Диалог массового открытия прокси в Telegram**:
  * При наличии в списке ровно одного сервера первая кнопка теперь лаконично озаглавлена «Подключить в Telegram» (вместо неуклюжего «все 1 стопкой»), а вторая — «Отправить в Telegram».
* **Плитка быстрых настроек (Quick Settings Tile)**:
  * Реализован гарантированный запуск службы при закрытом приложении через `MainActivity` (`ACTION_START_PROXY`): шторка сворачивается, приложение мгновенно открывается и поднимает прокси-сервер со 100% правами без системных запретов Android 14+.
  * Остановка службы выполняется мгновенно прямо в шторке в один клик без перехода в приложение.
  * Добавлена распаковка нативных библиотек (`extractNativeLibs="true"` и `useLegacyPackaging = true`) для быстрого доступа к ядру JNA.
* **Уведомление фоновой службы**:
  * Оптимизированы кнопки действий в постоянном уведомлении: оставлены две главные и емкие кнопки — «Подключить в Telegram» и «Отключить». Устранено обрезание текста троеточием в шторке.
* **Настройки**:
  * Параметр «Автозапуск» переименован в более точное и понятное «Автозапуск при перезагрузке» («Autostart on boot»).

## [1.0.0] - 2026-11-03

### Первый публичный релиз — All-in-One Edition

Добро пожаловать в первый официальный публичный релиз **Podlets TG Proxy** для Android!

#### Добавлено
* **Двухкомпонентная прокси-система**:
  * Высокопроизводительный резидентный локальный прокси-сервер на нативном ядре Rust прямо на Android (`127.0.0.1:[порт]`).
  * Встроенная балансировка через Cloudflare Workers/Pages и туннелирование с маскировкой FakeTLS.
  * Интеллектуальный радар и верификатор публичных MTProto-прокси.
* **Умный сканер и двухфазный чекер прокси**:
  * Автоматический сбор публичных прокси из проверенных каналов Telegram и лент TGStat.
  * Двухфазная проверка: мгновенный параллельный TCP-тест доступности с последующим криптографическим рукопожатием MTProto для замера истинного пинга.
  * Динамическая сортировка списка по задержке (сначала быстрые) или реакциям сообщества.
  * Цветовая индикация задержки (зелёный, жёлтый, красный).
  * Подключение в Telegram в 1 клик (`tg://proxy?...`), копирование ссылки и проверка собственных прокси.
  * Пакетные действия с прокси: открытие Топ-5 лучших серверов стопкой карточек в Telegram или отправка всего списка сообщением в чат / «Избранное».
  * Автономный кэш: сохранность проверенных прокси между запусками приложения.
* **Глубокая интеграция с системой Android**:
  * Фоновая служба (Foreground Service) с постоянным уведомлением и 3 быстрыми кнопками: «Подключить прокси», «Перезапустить», «Отключить».
  * Плитка быстрых настроек (Quick Settings Tile) в шторке уведомлений для мгновенного включения/отключения прокси из любого места.
  * Автозапуск при загрузке устройства (`RECEIVE_BOOT_COMPLETED`).
* **Журнал событий реального времени (Логи)**:
  * Встроенный терминал логов (модальная шторка в шапке приложения) с потоковым выводом logcat для процесса приложения.
  * Захват диагностических сообщений нативного демона Rust и Kotlin-чекера.
  * Агрегация повторяющихся записей, фильтрация по уровням (Инфо / Предупреждения / Ошибки), очистка и экспорт логов.
* **Современный интерфейс Material 3**:
  * Полная поддержка динамических цветов Material You на Android 12+.
  * Тёмная, светлая и системная темы с возможностью выбора пользовательских цветовых палитр.
  * Плавная нижняя навигация и анимированные переходы между экранами.
* **Гибкие настройки**:
  * Надежное хранение параметров через Jetpack DataStore Preferences.
  * Настройка портов, ключей, доменов FakeTLS/Cloudflare.
  * Управление источниками лент прокси: добавление, удаление и сброс к проверенным по умолчанию.
  * Проверка наличия обновлений через GitHub Releases.
